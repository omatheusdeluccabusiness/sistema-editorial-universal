# Seu projeto editorial

Esta pasta inteira representa uma marca e deve ser aberta como projeto no Codex. A skill está em `.agents/skills/social-media-editorial` e a configuração em [marca.md](.agents/skills/social-media-editorial/cliente/marca.md).

Primeiro pedido:

> Use $social-media-editorial para configurar meu sistema editorial. Faça uma entrevista comigo, uma pergunta por vez, e salve as decisões para continuarmos em outra conversa.

Se já tiver briefing, textos e referências aprovadas, forneça-os junto.

Depois da configuração:

- `Monte a operação editorial da semana.`
- `Execute o conteúdo de hoje.`
- `Revise esta peça segundo minha voz.`
- `Aprovado. Monte esta peça no editor.`
- `Publicado. Atualize o calendário.`

O calendário está em [operacao/calendario.md](operacao/calendario.md). O editor abre por `editor-carrosseis/ABRIR-EDITOR.cmd`.

Se a skill não aparecer, confira [TESTE-RAPIDO.md](TESTE-RAPIDO.md). Não abra somente uma subpasta: abra esta raiz.
