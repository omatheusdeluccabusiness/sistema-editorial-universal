# Validação da base e de cada cliente

## Verificação técnica da matriz

Conferir frontmatter da skill, resolução dos links locais, presença dos documentos de configuração, preservação das pastas ocultas no ZIP, ausência de caminhos dependentes do computador do mentor e funcionamento do editor com os quatro templates incluídos. Essa checagem não atesta qualidade da redação.

## Testes editoriais no Codex do cliente

Use uma cópia do projeto e pedidos reais. Registre resultado observado, correção e aprovação em cliente/exemplos.md e cliente/decisoes.md. Aplique apenas testes relevantes aos formatos ativos.

| Situação | Comportamento esperado |
|---|---|
| Cópia vazia: “Crie o conteúdo de hoje” | Identifica configuração inicial e começa pela informação essencial, sem inventar nicho, crenças ou CTA |
| Briefing fornecido pelo cliente | Aproveita os dados e pergunta somente pelas lacunas decisivas |
| Marca de atuação local | Respeita o território definido e não impõe equilíbrio Brasil/mundo |
| Marca com público brasileiro e pauta internacional | Pode escolher pauta internacional quando relevante, sem nacionalidade obrigatória |
| Dois clientes com posições diferentes | Preserva cada posicionamento, sem importar a orientação de outra marca |
| Tema não fornecido, curadoria delegada | Escolhe pauta fundamentada no documento da marca e no histórico |
| Gancho e template já informados | Prossegue sem repetir a pergunta |
| Preferência por perguntar o gancho em cada nova peça | Pergunta antes de redigir; preserva a escolha nas revisões |
| Notícia sem fontes acessíveis | Informa que falta apuração e não entrega material como notícia confirmada |
| Referência incerta ou citação de memória | Busca original, atribui incerteza ou retira a afirmação |
| Relato pessoal não fornecido | Não escreve confissão ou experiência fictícia em nome do cliente |
| Texto aprovado enviado ao design | Distribui o mesmo texto, sem reescrever silenciosamente |
| Template com áreas obrigatórias de imagem | Identifica e preenche todas as áreas ou informa a pendência concreta |
| Copy aprovada enviada ao editor | Importa cada bloco `SLIDE N` no slide correspondente e abre a URL nova |
| Escolha de template inválida | Interrompe com erro claro; não substitui silenciosamente por outro template |
| Template proprietário ausente | Não oferece nem tenta gerar o ANB Style |
| Pedido de uma peça por vez | Entrega uma e aguarda feedback |
| “Aprovado” | Marca como aprovado, nunca como publicado |
| Retomada em nova conversa | Consulta arquivos, retoma próxima ação e preserva etapas aprovadas |
| Notícias desativadas | Não preenche o calendário com notícias por hábito |
| Vídeo ativo | Entrega fala completa e esqueleto conforme configuração |

## Critério de aceitação

A matriz está utilizável quando seus arquivos são íntegros. A implantação do cliente está pronta para rotina quando as definições essenciais estão aprovadas e os formatos ativos têm exemplos aprovados com novos temas. Pendências de integração visual não impedem criação de texto, mas impedem afirmar montagem concluída.
