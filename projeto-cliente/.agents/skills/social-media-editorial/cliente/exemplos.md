# Exemplos aprovados

Nenhum exemplo aprovado.

Para cada teste, registrar:
- Linha, formato, template e tema.
- Arquivo da versão avaliada.
- Trechos aprovados e por que funcionam.
- Trechos rejeitados, correção e motivo.
- O que vale apenas para esta peça.
- Regra que o cliente aprovou para próximas peças.
- Data e responsável pela aprovação.

Exemplos orientam qualidade e voz, sem transformar todo assunto futuro na mesma narrativa. Não usar depoimentos, números ou experiências de uma amostra como fatos de outra peça.
