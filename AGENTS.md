# Sistema Editorial deste projeto

Para qualquer pedido de estratégia, curadoria, pesquisa, escrita, revisão, calendário ou design de conteúdo para redes sociais, use a skill `social-media-editorial` em `.agents/skills/social-media-editorial/SKILL.md`.

Leia os arquivos da marca antes de produzir. Os padrões editoriais continuam ativos mesmo quando a configuração particular ainda está incompleta.
